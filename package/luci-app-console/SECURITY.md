# 防火墙与设备流量

一级菜单「防火墙」包含安全总览、地区访问控制、设备流量、流量分析、日志与数据库。首次安装默认没有启用的地区限制，由管理员预览并应用规则。允许通过地区层后仍须通过 firewall4 原有规则；本模块不开放任何端口，也不建立端口映射。

## 地区规则

- 国家/地区级，IPv4、IPv6 同时支持。来源 DB-IP Country Lite，CC BY 4.0；使用结果的页面保留 DB-IP 链接。不是省市库，不能保证代理、CDN或VPN背后的真实位置。
- 方向：WAN→本机 INPUT、WAN→LAN 转发、LAN→WAN 转发。端口映射入站按映射后的内部目标端口匹配。设备限定按后台当前识别的 MAC→IP 绑定更新，不是防 MAC/IP 冒用机制。
- 优先级：允许 IP/CIDR 例外 → 阻止例外 → 自上而下的地区规则。允许规则对其限定的方向、设备和端口形成白名单，未知/未选地区阻止；阻止规则只阻止其选中地区，未知地区继续通过地区层。
- 规则仅作用于新建和未跟踪的连接，已经建立的连接不会强行断开。DHCPv4续租、IPv6邻居发现及错误控制报文保留。LAN访问本机管理界面不经过WAN地区门控。
- 每次应用先 `nft -c` 检查，再原子替换独立的 `inet console_guard` 表，保存120秒回滚标记；计时采用本次启动的单调运行时间，校时不会延长或缩短确认窗口。后台服务与独立计时进程均可执行超时回滚。确认才保留变更。
- 相同地区组合复用区间集合，最多100条规则、合计50万个地区网段，超额拒绝应用。每条规则日志限速2条/秒，全局最多10条/秒；日志与阻止动作分开，日志限速不会放行数据包。
- 规则计数自本次加载开始，应用、数据库更新或绑定重建可能重置规则计数；不是永久攻击次数。界面最多读取200条系统日志。

## 采集与分析

`console-security` 是 procd 开机服务，2秒采样一次独立的 `inet console_meter` 动态集合。计数链在 firewall4 转发过滤之后，统计获允许的 LAN↔WAN 流量；按内部 IPv4/IPv6 与协议计数，再根据 DHCP/邻居主机信息归并 MAC。未知身份保留为 IP 设备。IP地址变化前的未知历史不会强行并入另一台设备。

计数采用IP层字节，不等于文件/应用有效载荷。普通LAN同网段交换、路由器本机进出流量、下级NAT隐藏终端无法逐台完整统计。VPN等不属于WAN区域的出口不在默认LAN↔WAN统计范围。开启软件或硬件流量卸载会绕过常规计数路径，界面会提示不准确；本版本按未开启卸载的准确模式设计，不会擅自修改用户的卸载设置。

协议总量来自内核TCP/UDP/其他协议计数。热门目的连接来自每30秒一次的 conntrack 原始/回复双向元组采样，可关联端口映射的内部响应设备。最多处理4096条当前会话，系统连接超过20000时暂停分析以保护转发性能。短连接、采样间结束的连接可能漏采，地区排行仅针对采样热门连接，不能当作完整地区字节账单。不启用DPI，不读取通信内容，不按端口伪造应用识别结果。

设备在线是最近120秒有上网转发流量，不等同于DHCP租约存在。设备连接数是会话采样值，最多滞后30秒。连接数超过1000或单设备采样速率超过50MiB/s会显示流量提醒；提醒不代表攻击。历史曲线显示各区间已经记录的上传/下载字节，首尾区间可能不足完整周期，不将未采集时间补成0后计算伪平均速率。

## 存储与更新

- 配置及回滚：`/etc/console-security/`；运行缓存与任务状态：`/tmp/console-security-*`。
- 历史库：`/srv/console-security/traffic.db`，WAL模式，每分钟事务批量保存。近24小时分钟数据，更早5分钟聚合，保留7天，查询最多600点。数据量不足的区间不补0。
- 历史库限制100MiB，超过80MiB或根盘空间紧张会优先清理旧数据；可用空间低于100MiB暂停历史写入，实时计数继续，并显示警告。磁盘暂停期间的历史不补成虚假的均匀流量。
- 累计计数与原始快照一起事务保存。采集进程重启时从同一次内核计数基线恢复；重启路由器/内核计数表重建后重新建立基线，不累计负数或虚假峰值。异常关机期间未持久化的数据可能丢失。
- 内核动态计数项在7天无活动后过期，接近容量上限时显示不完整警告。已识别MAC的累计账目保留；长期未活动的未知IP身份按7天清理，避免IPv6隐私地址无限占用。
- 国家库：`/srv/console-security/geo-*.db`，单版本不超过100MiB。每月更新，当前月未发布时尝试上月。临时文件在内存/tmp，校验CSV、IPv4/IPv6范围、记录数、数据库行数后切换，失败保留已有版本。空间许可时保留一个上版；空间不足先删过期备份，保留当前有效版本。
- 自动更新需要设备能通过HTTPS访问 `download.db-ip.com`。本次实机没有WAN默认路由（`ip route get 1.1.1.1` 返回 Network unreachable），首次库通过开发机从官方HTTPS下载后中转导入，版本2026-10、710834条。本功能不擅自修改网关或默认路由；后续下载失败会在「日志与数据库」显示，不会清空已安装库。
- rootfs仅约496MiB，不能无限保存历史；扩大历史周期前应先扩容。重启保留记录，刷写/重装固件是否保留取决于升级备份策略。

## 集成

本模块使用 firewall4 `ruleset-post` 自动包含的独立规则文件 `/usr/share/nftables.d/ruleset-post/90-console-guard.nft`，指向生成文件 `/etc/console-security/guard.nft`。原生防火墙重载会重新加载地区门控；设备计数表由采集服务单独维护，正常 fw4 重载不清零设备计数。

依赖 sqlite3-cli、firewall4、conntrack、ucode fs/ubus/uci/uloop、uclient-fetch、CA证书。菜单、RPC与ACL均在自定义包内，后续构建可带入；直接部署的实机由 `/etc/init.d/console-security` 启停。服务停止只停止采集，已应用的地区规则仍在内核中；关闭地区限制应清空/禁用规则并应用确认。

## 验证

`tests/console-security-policy.uc` 验证前缀、地区、端口、方向、例外与非法输入，并生成隔离测试规则。`tests/console-security-netns.sh` 必须通过 `unshare -n` 运行，测试真实 IPv4/IPv6 阻止、允许及未知地区；`console-security-counter.uc` 核对44/64字节的实际IP层计数。

`console-security-lifecycle.uc` 只允许初始空规则环境，先启动不改变访问范围的120秒应用窗口，期限后验证自动回滚，再验证确认及手动回滚。`console-security-history.sql/uc` 仅在/tmp专用数据库构造100设备、316800条记录，核对分设备汇总和600点上限。`console-security-browser.cjs` 只读检查5个页面、草稿、命中预览与移动端，不提交防火墙规则。

隔离实包测试需要临时安装 ip-full 和 unshare，并非运行时依赖；本次验证后已清理。`console-security-recovery.uc` 也必须在隔离网络命名空间运行，验证内核表缺失时从保存文件恢复规则。

2026-11-01 实机验收结果：IPv4/IPv6地区阻止、白名单及未知地区拒绝通过；IP层44/64字节计数准确；120秒自动回滚、确认、手动回滚和不受墙上时钟影响的计时检查通过。5次真正的LAN→已连通WAN网段UDP请求产生285字节上传、425字节ICMP错误回复下载，内核、MAC归并、协议总量和SQLite历史一致，采集服务重启后保留。fw4检查和重载通过，独立设备计数表未被重置。

100设备、316800条隔离历史记录下，两个查询合计约50–310ms；5个新页面复查约259–298ms，无脚本错误，移动端无横向溢出。原有22项概况/VPN模型测试通过。当前WAN无默认路由，因此未执行真实外网转发吞吐压测；隔离实包及连通WAN网段功能测试不代表实网Mbps吞吐结果。
