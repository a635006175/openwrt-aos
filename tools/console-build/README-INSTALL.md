# OpenWrt 安装说明 — 20261107-LANandcall

当前唯一交付镜像为 openwrt-console-installer.iso。系统内部、安装器菜单和发行清单均标记为 20261107-LANandcall。

本版已清除 OpenVPN 全部账号、客户端/服务端配置、证书密钥及相关备份，清除 Mihomo 配置、订阅、控制密钥及相关备份，清空 DDNS 已保存的服务商实例。OpenVPN、Mihomo 默认关闭且不自动启动。安装后需要重新导入配置、添加账号或 DDNS 服务。威胁统计等保留数据库逐一校验，内容未改变。

启动菜单、磁盘选择、LAN/WAN 选择、写盘确认、校验与完成提示均提供中英文双语，镜像内置提示所需的中文字体。BIOS/UEFI 图形控制台均检查了实际显示及键盘输入。

本次包含 PVE 无串口图形控制台修复：默认第一项使用本地显示和键盘，PVE/noVNC 直接选择第一项。仅使用串口终端时选择第二项 (serial console)。安装器保持 PID 1 存活，退出救援 shell 不再触发自动重启。已按 4 GiB、4 核、SeaBIOS/i440fx、SATA 光驱、E1000+VirtIO、无串口配置验证显示、键盘和退出恢复。

本版基于已与本地开发源码核对的程序快照，重新生成 BIOS/UEFI 磁盘载荷及混合引导 ISO；沿用与开发机匹配的 6.18.55 内核。本次没有从头重编内核或工具链。

已通过静态检查，以及光盘 BIOS、光盘 UEFI、U盘 BIOS、U盘 UEFI 四种虚拟机实际安装验证。每次均检查写盘回读、自定义 LAN/WAN 与地址落盘、安装后 155 个程序文件哈希和版本号。另通过 BIOS、UEFI 安装盘从硬盘启动测试，系统版本正确，态势感知 overview 接口返回正常。验证详情见同目录的 20261107-LANandcall-verification.json。

## 安装

1. 虚拟机挂载 ISO；物理 U 盘使用镜像写入工具的 DD 模式写入。按目标机器选择 BIOS 或 UEFI，安装后保持相同启动模式。
2. 安装器列出磁盘和网口。核对型号、容量后，输入安装目标整盘路径，例如 /dev/sda。
3. 按编号选择 LAN 网口，输入 LAN IPv4/前缀，默认 192.168.1.1/24。网口选择必须输入编号或 d，空回车不会跳过。
4. 选择 WAN 网口；仅剩一个候选时自动采用，也可输入 n 不配置 WAN。其余口不主动配置。
5. 核对磁盘、网口和地址摘要。最终确认处按回车会清空目标盘全部数据，输入其他内容取消。
6. 等待写盘、回读及网络配置复验全部完成。按提示输入 poweroff -f 关机，或 reboot -f 重启，移除安装介质，从硬盘启动。
7. 电脑接所选 LAN 口，通过安装时设置的 LAN 地址访问管理页面。设置 root 密码，再按实际网络配置 WAN、DNS、DHCP。

根分区为 6 GiB，不会自动扩展到整盘。镜像保留数据库，已移除 VPN 私钥、地区及端口映射规则。

## 维护

唯一安装器脚本目录为 .dsh/skills/openwrt-installer-image/scripts。指定发行版本时须同时更新 rootfs 内版本元数据，完整生成载荷，再运行 build-iso.sh --version <版本号>。正式发布前运行 check-iso.py 和 verify-e2e.sh。

开发期间仅同步代码；收到明确打包要求后才生成镜像。固定发布入口保持不变，旧交付镜像由最新通过验证的版本替换。构建输入 router-build/rootfs、bootsrc、out、keepbin 和验证证据需要保留。
