# 系统概况接口详情

2026-11-07：已部署开发实机192.168.1.1。编译机10.0.0.10的console-sync与openwrt-console-build两份源码已同步；未编译包或镜像。修改前核对了四个文件在本地、实机和编译机的内容一致。

接口图标支持鼠标悬停、键盘聚焦与点击固定显示详情。详情展示逻辑接口与物理链路状态、IPv4/IPv6及委派前缀、接口DNS和搜索域、默认网关、协议、MAC、MTU、连接时长、协商速率、双工模式、桥接成员网口、实时接收/发送、累计流量/包数/丢包/错误。地址与DNS支持多条，不再只显示名称和已连接。

悬停面板可滚动，鼠标移入面板后保持打开；支持Esc、关闭按钮及点击外部收起。更新数据时保留当前面板与焦点。面板会按视口调整位置、宽度与高度；修复主题固定桌面网格使窄屏接口图标被后续卡片覆盖的问题。重要IP、DNS和链路字段优先展示。

沿用现有network.interface.dump及luci-rpc.getNetworkDevices，只新增所有设备的RX/TX采样计算，不改变WAN汇总统计。实时收发按设备视角展示，每5秒更新；协商速率不是实时流量。桥接不编造聚合协商速率，展示成员网口。硬件不提供速率/双工时明确显示“未提供”，断开则显示“未连接”。接口DNS为空时不会挪用其他接口DNS。

验证：20项Node测试通过；实机Edge无头浏览器检查桌面悬停、面板悬停、自动刷新保持打开、键盘聚焦、Esc、关闭按钮、375px窄屏位置均通过，无页面JS错误。已查看实机桌面、LAN与窄屏截图，位于.stage/interface-hover/。本地与实机四文件SHA256一致；编译机两源码目录逐文件cmp一致。
